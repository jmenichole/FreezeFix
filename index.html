❓ How to use FreezeFix

Body-double: Mark a task for body-doubling when you want accountability or to pair with someone (a friend, coworker, or coach). It flags the task visually and can be used with external scheduling or reminders.

Break it Down: Use the 🪄 button on any task (or from the Add/Edit task modal) to generate micro-steps. AI will try to create 3–6 tiny steps; if no AI key is configured, the app falls back to local heuristics.

Energy & Action Plan: Set the Energy level to match how you feel now (High / Medium / Low). Use Action Plan to decide whether to Do, Delegate, or Delete a task quickly.

Screen Vision & Tracker: The Screen Vision helper requires the local sidecar script (tracker.py). Open Settings → Screen Vision Helper and press Check / Start, or run python tracker.py from the app folder. Tracker enables screen capture and a local proxy for integrations.

GitHub import: Removed from the UI to simplify the product. If you need GitHub imports later, they can be re-added as an explicit opt-in connector.

Tip: Add quick tasks with Brain Dump, then use Break it Down to turn intimidating tasks into tiny steps you can complete in short bursts.
