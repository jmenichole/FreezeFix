Privacy Policy for FreezeFix

Effective Date: November 8, 2026 | Last Updated: November 8, 2026

1. Core Privacy Philosophy

FreezeFix is designed from the ground up to respect user privacy and executive function. We believe your productivity data, task lists, and focus patterns belong strictly to you. FreezeFix does not operate user tracking, does not run ads, does not collect analytics telemetry, and does not sell any personal data.

2. What Data Is Collected and Where It Is Stored

  • Tasks and Settings: All tasks, categories, durations, focus timer presets, and customization options are stored strictly locally on your device using your browser's local storage (localStorage). No tasks are ever sent to an external FreezeFix server.
  • Calendar Files (.ics): If you import a Google Calendar .ics file, it is parsed locally in your browser memory. We never upload your calendar files to external servers.

3. Artificial Intelligence & API Keys (BYOK)

FreezeFix offers optional AI features (such as "Magic Breakdown" and "What next?" suggestions):

  • Built-In Offline Fallback: FreezeFix includes local rule-based heuristics that operate 100% offline with zero network requests.
  • Direct API Connections: If you choose to connect an AI provider (e.g., Google Gemini or Groq), you provide your own API key. The extension communicates directly with that provider over an encrypted HTTPS connection. FreezeFix has no intermediate proxy server and never sees or stores your API keys outside your device's local storage.

4. Screen & Tab Capture Permissions

The Chrome extension requests the activeTab permission solely for the user-triggered "📸 Scan Screen" feature:

  • Screen snapshots are captured only when you explicitly click the Scan button or use the keyboard shortcut.
  • Snapshots are sent directly to your configured AI vision provider for real-time analysis and are discarded immediately after processing. They are never retained, logged, or shared with third parties.

5. Children's Privacy

FreezeFix does not knowingly collect or solicit personal data from children under the age of 13. Because all data is stored locally on the user's device, no personal identifiers are collected.

6. Changes to This Policy

If we update this Privacy Policy, changes will be posted to this page and documented in our open-source GitHub repository changelog.
