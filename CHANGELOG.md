# Changelog

All notable changes to FreezeFix are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## How to maintain this changelog

Every change to the project should add an entry here. For each change, record:

- **What** changed (a short, user-focused description).
- **Who** made it (name/handle).
- **When** it was made (ISO date, `YYYY-MM-DD`).

Add new entries under `## [Unreleased]`, grouped by type: `Added`, `Changed`,
`Fixed`, `Security`, `Removed`, `Deprecated`. Each bullet ends with an attribution
in the form `— <author>, <YYYY-MM-DD>`. When cutting a release, rename
`[Unreleased]` to the version and date, and start a fresh `[Unreleased]` section.

Entry template:

```
- <what changed> — <author>, <YYYY-MM-DD>
```

## [Unreleased]

### Security
- Escape all user-, AI-, and calendar-derived values rendered via `innerHTML`
  (timeline, task list, breakdown steps, history, AI output) with a new
  `escapeHtml` helper (`js/util.js`), closing an XSS→RCE risk. — Cursor Agent (for jmenichole), 2026-08-19
- Add a strict `Content-Security-Policy` to `index.html` and `heart.html`;
  externalize inline scripts (`js/heart-widget.js`, `js/heart-open.js`) and
  convert task-list inline `onclick` handlers to delegated listeners so
  `script-src 'self'` holds. — Cursor Agent (for jmenichole), 2026-08-19
- Lock down the `tracker.py` sidecar: bind to `127.0.0.1`, restrict CORS to the
  app origin (websites can no longer read `/capture`), and require a per-session
  `FREEZEFIX_TRACKER_TOKEN` on sensitive endpoints. `main.js` generates the token
  and passes it to the renderer and the spawned tracker. — Cursor Agent (for jmenichole), 2026-08-19

### Fixed
- Timeline now only places tasks scheduled for the current day, preventing
  future-day tasks from overlaying today's schedule. — Cursor Agent (for jmenichole), 2026-08-19
- The "Skip" button now advances past skipped tasks (session `skippedIds` set)
  instead of doing nothing. — Cursor Agent (for jmenichole), 2026-08-19
- Renderer tracker starter tries `python` then `python3` (mirrors `main.js`);
  removed an unused variable in `renderAll`. — Cursor Agent (for jmenichole), 2026-08-19

### Added
- Stats bar (streak / done today / tasks left) and 7-day activity week grid in
  the UI, wiring up the previously orphaned `renderStats()` / `renderWeekGrid()`
  code. — Cursor Agent (for jmenichole), 2026-08-19
- App icon (`build/icon.ico` + `icon.png`) generated by `build/generate_icon.py`,
  wired into electron-builder (`win.icon` and NSIS installer/uninstaller/header
  icons). — Cursor Agent (for jmenichole), 2026-08-19
- Design spec at `docs/superpowers/specs/2026-08-19-freezefix-enhancements-design.md`. — Cursor Agent (for jmenichole), 2026-08-19
- This changelog. — Cursor Agent (for jmenichole), 2026-08-19

### Changed
- Replaced raw `prompt()` dialogs with in-app UI: the Calendar connector focuses
  the Settings iCal URL field, and Backup/Restore are now two explicit buttons. — Cursor Agent (for jmenichole), 2026-08-19
- CI release workflow now uses Node 20 (`actions/setup-node`). — Cursor Agent (for jmenichole), 2026-08-19
- README documents the optional Python + Pillow requirement for Screen Vision and
  how app icons are generated. — Cursor Agent (for jmenichole), 2026-08-19
